# Security Policy

This repository publishes defensive security research and advisories for
already-disclosed vulnerabilities.

## Reporting a problem with an advisory

If you believe an advisory contains an error, an overstated claim, or a
reproducibility gap, please open a GitHub issue on this repository describing:

- the affected advisory (CVE ID),
- the specific statement in question, and
- the evidence or reference that supports a correction.

Corrections are welcomed and are treated as first-class contributions.

## Coordinated disclosure

Advisories here cover vulnerabilities that already have public identifiers and,
where applicable, vendor fixes. If you are researching an **undisclosed**
vulnerability, please report it to the affected vendor or a coordinating body
first; this repository is not a channel for zero-day disclosure.

## Scope

Published material is limited to defensive validation, detection, and
reproducibility. It does not include weaponized exploit code, and validators
do not target live systems. See [`METHODOLOGY.md`](METHODOLOGY.md).
