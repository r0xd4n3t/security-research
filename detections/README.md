# Detections

Candidate detection content derived from the advisories in this repository.

- **`sigma/`** — one Sigma rule per advisory, marked `status: experimental`.

These rules are **starting points, not validated production signatures**. Field
names, log sources, and thresholds must be adapted to your own telemetry, and
each rule should be tested for coverage and false positives before deployment.
Detection guidance for each issue is also documented in its advisory.
